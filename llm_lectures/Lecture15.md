# Lecture 15

如何把一个 “会续写文本” 的预训练语言模型，训练成一个能够遵循指令、符合偏好、具备安全边界且可调用工具的助手。

## 知识路线

预训练模型 -> 行为数据设计 -> 监督微调（SFT, 模仿目标行为） -> 中期训练（扩大行为数据并减轻遗忘） -> 偏好数据 -> RLHF -> PPO & DPO -> 过度优化和模型坍缩（对齐的副作用）

### 预训练模型

如何在预训练之后塑造模型行为？基础模型为什么不能自然等价于助手？
因为缺少稳定的指令跟随目标。

### 行为数据设计

预训练数据规模大但目标不完全匹配，因此要收集“我们希望模型表现出的行为”。
三个研究问题是：数据长什么样、怎样利用数据、是否必须依赖大规模数据。这三个问题分别对应的数据、算法和规模分析。
 
### SFT

监督微调（Supervised Fine-Tuning SFT）的目标是让模型在给定输入 (x) 时，提高目标输出 (y) 的概率。

##### Open SFT Data 的演进

1. FLAN 从任务集合出发。
2. Self-Instruct 和 Alpaca 用模型生成指令。
3. ShareGPT/Vicuna 引入真实对话。
4. OpenAssistant 强调长对话与详细回答。
5. WizardLM 提高指令复杂度。
6. Tulu3 强化配方与评测。
7. Nemotron 等开始纳入工具和智能体轨迹。

演进方向有三个显著变化：

1. Chattiness 即回答从短答案走向更自然、更长的交流。
2. Detail 即信息和解释更丰富。
3. Tool Use 即输出空间从 token 序列扩展到可执行动作。

#### 风格、评测与知识注入的边界

SFT 学到的不只是“答案内容”，而是训练数据中完整的输出分布，数据风格会迁移到模型：不同训练数据的平均长度、语气和结构不同，微调后的模型也会表现出明显的响应长度差异。SFT 不只是教“答对”，也在学习风格分布。

人类和基于 GPT 的评审往往偏爱更长、更详细的回答。这会造成 verbosity bias：回答因更长而获胜，而非因为更准确。

此外，模型在用户偏好榜单上提升排名，但知识、推理基准变化有限，这是因为风格变化未必显著提升 benchmark，偏好榜单和 benchmark 的评测是不同的维度。

SFT 在知识注入上的边界：第一，不宜把行为微调当成尾部知识数据库；第二，带有正确性反馈的优化可能比单次模仿更合适；第三，知识的存储、提取和表达相互纠缠。需要动态知识时，检索与工具通常比单靠 SFT 更可靠。

所以不同类型的知识和行为适合通过不同方式获得：
1. 稳定、广泛、重复出现的知识可以通过预训练或中期训练进入参数；
2. 任务格式和回答方式通过 SFT 学习；
3. 正确性、拒答和工具选择通过反馈优化；
4. 冷门、精确、动态事实通过检索和工具获得。


#### 安全 SFT 与少量高质量行为数据

少量数据也能显著改变安全行为，约 500 条有针对性的样本即可明显改善仇恨言论或 harmlessness 指标。这说明预训练模型往往已经具备理解规范的能力，SFT 主要是在激活并稳定输出该行为。

SFT 最擅长提取预训练中已有的潜在行为，而不是凭少量样本创造新知识；即使正确的新事实也可能带来副作用；安全、风格和指令跟随可被少量优质数据显著改变，但长尾覆盖仍受益于规模。

关键行为的启动不一定需要海量数据，但部署可靠性需要覆盖长尾，而“500 条有效”不等于“500 条足够”。

覆盖长尾是指：
1. 少量高质量数据，可以快速改变模型的总体行为倾向；
2. 但真实输入空间非常大；
3. 大量罕见场景无法靠少量样本全部覆盖；
4. 数据规模和多样性越大，模型在边缘场景中的行为通常越稳定。

少量数据能教会模型“原则”，大量多样数据才能让这个原则覆盖各种罕见情况。

#### Mid Training

SFT 通常就是对目标回答执行 teacher forcing 和梯度下降，最小化 token 级交叉熵。真正的新问题是：当数据和算力都很大时，如何扩大指令训练而不破坏基础能力。


**Mid-training（中期训练）**位于基础预训练和最终后训练之间：

```text
基础预训练 → Mid-training → SFT / RL
```

它仍然以大规模语言建模为主，但会有意识地调整训练数据分布，使模型从原来的基础能力平稳迁移到目标能力分布。


Mid-training 常用于改变模型的：

* 数据领域，如通用领域迁移到代码、数学或医学；
* 上下文长度，如从短上下文扩展到长上下文；
* 语言比例，如增加中文或其他低资源语言；
* 指令数据比例，使模型提前适应问答和指令形式；
* 能力分布，如增强推理、工具使用或特定领域能力。

其核心目的不是直接规定模型“应该怎样回答”，而是：

> 先调整模型的知识、数据域和基础能力分布，为后续 SFT 做准备。


为什么不直接进行大规模 SFT？

纯指令数据与预训练语料的分布差异较大。如果直接进行长时间、大规模 SFT，可能导致：

* 灾难性遗忘，损害基础语言和知识能力；
* 过度学习指令数据的风格；
* 输出分布快速偏移；
* 通用能力下降。

因此可以在后期预训练阶段混合：

```text
通用预训练语料 + 指令数据 + 目标领域数据
```

通用语料负责维持原有能力，目标数据负责推动能力迁移。


Two-phase training

一种典型的两阶段方案是：

第一阶段：Mid-training 使用较大规模的混合数据训练：

```text
通用语料 + 领域语料 + 指令数据
```

主要完成知识、领域和能力分布的平稳迁移。

第二阶段：短 SFT 使用高质量纯指令数据进行较短训练，主要确定：

* 回答格式；
* 指令跟随；
* 语气和风格；
* 任务行为。

因此：

> Mid-training 负责“能力迁移”，SFT 负责“行为定型”。


| 阶段           | 主要目标             | 典型数据         |
| ------------ | ---------------- | ------------ |
| 基础预训练        | 建立通用语言、知识和基础能力   | 大规模通用语料      |
| Mid-training | 调整领域、语言、上下文和能力分布 | 通用语料与目标数据的混合 |
| SFT          | 学习任务格式和回答行为      | 高质量指令—回答数据   |


> Mid-training 不是替代 SFT，而是在预训练和 SFT 之间增加一个缓冲阶段：先用较大规模混合数据平稳改变模型的能力分布，再用较短的 SFT 将模型行为固定为目标形式。

### RLHF

SFT 拟合参考回答分布 (p^*(y|x))，需要“应该输出什么”的示范；RLHF 寻找使期望奖励 (_{yp}[R(x,y)]) 最大的策略，需要“输出有多好”的评价。前者是模仿，后者是决策优化。

#### 偏好数据不是客观真理

偏好数据把“人的价值判断”变成训练信号，但同时把标注者结构、报酬、文化、评审模型和风格偏差都带入模型。算法只能优化给定信号，不能自动修正信号代表性。

#### DPO

[DPO 的推导过程](https://zhuanlan.zhihu.com/p/19347053170)

涉及知识：Bradley-Terry 假设：人类偏好两个回答的概率，由它们潜在 reward 的差经过 sigmoid 决定。

DPO 常与 expert iteration 结合：每一轮 DPO 都是在固定偏好数据上进行的离线优化；但偏好数据不是永久固定，而是周期性地由最新模型生成候选并由专家重新标注。因此从整个多轮训练过程看，策略决定下一轮数据分布，新数据又推动策略更新，形成了近似策略迭代的闭环。

### 偏好优化的风险

RLHF 把语言模型从描述数据分布的模型推向追求高奖励的策略，输出熵下降，多样性和概率校准可能恶化。模型更“确定”不代表它更“正确”。

偏好数据收集本身困难并受大量混杂因素影响；PPO 等算法比 SFT 更复杂；无论 PPO 还是 DPO，都必须警惕对奖励的过度优化。

后训练目标不是把偏好分数推到最高，而是在真实性、多样性和基础能力之间寻找受约束的平衡。
